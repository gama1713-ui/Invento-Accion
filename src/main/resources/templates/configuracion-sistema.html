Configuración del sistema

Consulta la configuración técnica declarada por la aplicación sin mostrar secretos ni presentar valores simulados como estados reales.

Alcance: Esta página es informativa. No modifica variables de entorno, bases de datos ni parámetros del servidor.

Aplicación

Configuración declarada

Invento Acción utiliza Java 17 y Spring Boot 3.1.4 según la configuración del proyecto.

Persistencia

Depende del entorno

El proyecto declara H2 para funciones JPA y MongoDB para módulos que utilizan documentos. La conectividad efectiva depende del entorno de ejecución.

Servicios web

Información técnica

La aplicación publica funciones MVC y API. Esta vista no ejecuta una prueba automática de disponibilidad.

Correo

Configuración externa

El correo SMTP solo está disponible cuando MAIL_HOST, MAIL_USERNAME y MAIL_PASSWORD están configuradas. Los valores no se muestran.

Parámetros declarados

  • Puerto mediante PORT, con valor predeterminado 8080.
  • URL base mediante APP_BASE_URL.
  • MongoDB mediante MONGODB_URI.
  • Correo mediante variables MAIL_HOST, MAIL_PORT, MAIL_USERNAME y MAIL_PASSWORD.
