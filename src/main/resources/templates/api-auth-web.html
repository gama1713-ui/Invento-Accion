Modulo visual API Auth

Pantalla publica para probar el servicio web de autenticacion de Invento Accion. Desde aqui se puede registrar un usuario, validar el token e iniciar sesion consumiendo la API REST real conectada a MongoDB Atlas.

1 Registro de usuario

Este formulario llama al endpoint POST /api/auth/registro. La API crea el usuario, genera username, contrasena temporal y token de validacion.

2 Validacion de token

Este formulario llama al endpoint GET /api/auth/validar?token=.... Sirve para activar el usuario antes de iniciar sesion.

3 Inicio de sesion

Este formulario llama al endpoint POST /api/auth/login. La API valida el username y la contrasena contra los registros guardados en MongoDB Atlas.
