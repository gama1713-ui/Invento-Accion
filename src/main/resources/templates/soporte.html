Soporte de Invento Acción

Encuentra orientación para resolver dificultades comunes y preparar un reporte claro sobre el funcionamiento de la plataforma.

Importante: Invento Acción es un proyecto académico en desarrollo. El soporte se ofrece como orientación sobre el uso de la plataforma y no debe utilizarse para enviar contraseñas, credenciales o información confidencial.

¿Cómo podemos orientarte?

Antes de reportar un problema, identifica el módulo, la acción realizada y el mensaje mostrado por el sistema.

Acceso a la plataforma

  • Verifica el usuario o correo ingresado.
  • Confirma que utilizas la contraseña correspondiente.
  • Revisa si la cuenta requiere validación del correo.
  • No compartas tu contraseña al solicitar ayuda.

Activos y movimientos

  • Completa los campos obligatorios.
  • Verifica cantidades, categoría, ubicación y estado.
  • Evita repetir una operación mientras se procesa.
  • Anota el mensaje visible si ocurre un error.

Reporte de errores

  • Indica el módulo y la acción realizada.
  • Describe el resultado esperado y el observado.
  • Incluye el mensaje de error y la fecha del evento.
  • Evita adjuntar datos personales innecesarios.

Información útil para solicitar ayuda

Un reporte claro facilita la revisión del problema. Puedes preparar los siguientes datos sin incluir contraseñas ni secretos de acceso.

Datos recomendados

  • Nombre y correo para recibir respuesta.
  • Módulo donde ocurrió la dificultad.
  • Descripción breve y ordenada de lo sucedido.
  • Mensaje de error visible, si existe.
  • Fecha del incidente.

Datos que no debes enviar

  • Contraseñas.
  • Tokens de validación.
  • Credenciales de bases de datos o correo.
  • Llaves de acceso o secretos del entorno.
  • Información personal que no sea necesaria para la solicitud.

Preguntas frecuentes

Sí. Actualmente se presenta como un proyecto académico gratuito.

No se presenta como una solución empresarial certificada. Su adopción en un entorno real requiere evaluación, pruebas y controles adicionales.

Los activos se gestionan desde el módulo correspondiente, disponible para usuarios autorizados según la configuración de la plataforma.

Prepara un reporte con el módulo, la acción realizada, el resultado observado y el mensaje de error. El canal de contacto deberá estar habilitado antes de enviar información personal.

Canales y más información

El formulario de contacto se encuentra dentro del alcance de actualización de este módulo. Solo deberá confirmar la recepción cuando el mensaje quede registrado o sea enviado realmente.
