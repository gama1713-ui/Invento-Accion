Dependencias técnicas

Configuración de integraciones

Identifica los servicios externos declarados por Invento Acción sin revelar credenciales ni asumir que están disponibles.

Alcance: Una integración configurada no equivale a una integración verificada. La conectividad debe comprobarse en el entorno correspondiente.

MongoDB

Variable externa

La aplicación utiliza MONGODB_URI para módulos MongoDB. Esta vista no expone la cadena de conexión.

SMTP

Variable externa

El servicio de correo depende de host, puerto, usuario y contraseña configurados fuera del código.

Render

Alojamiento

El proyecto se publica en Render. La disponibilidad y configuración se administran desde ese servicio.

Recursos CDN

Recursos visuales

Bootstrap y Font Awesome se cargan desde proveedores externos en las plantillas.

Validación recomendada

  • Comprobar conectividad sin imprimir secretos.
  • Registrar errores sin incluir credenciales.
  • Separar configuración local y producción.
  • Documentar qué datos recibe cada proveedor.
